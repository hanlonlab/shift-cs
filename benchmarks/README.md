# Benchmarks

This directory contains measurements for latency-sensitive and allocation-sensitive paths.

- [Replay comparison](Shift.ReplayBenchmarks/README.md): TAQ parsing, recorded replay, order-count scaling, and a common input for SHIFT, HftBacktest, and NautilusTrader.

## Belongs here

- Reproducible benchmark projects and their documented workloads.

## Does not belong here

- Correctness tests or unrepeatable performance scripts.
